# Qótimo Sorvetes — site

Site estático (HTML, CSS e JavaScript puros, sem build).
Tudo o que é publicado está na pasta `site/`.

## Rodar no computador

```
cd site
python -m http.server 8000
```

Abra http://localhost:8000.

## Publicar na Vercel

- Root Directory: `site`
- Framework Preset: `Other`
- Build Command e Output Directory: vazios
