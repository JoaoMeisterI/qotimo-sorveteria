# Pacote de implementação — faixa de benefícios Qótimo

Este pacote orienta a revisão do espaço branco entre o herói e a seção Nossa História do repositório `JoaoMeisterI/qotimo-sorveteria`, pasta `site/` da branch `master`.

## Conteúdo

- `PROMPT-CLAUDE.md`: instruções de implementação e critérios de revisão.
- `assets/fecho-faixa-branca.svg`: borda inferior branca com curva limpa; substitui a geometria da `.historia__topo`.
- `assets/acentos-laterais.svg`: pequenos respingos de calda vermelha e curvas azul-marinho para as laterais da faixa.
- `referencias/aprovado.png`: referência visual da composição desejada, para orientação, sem uso como fundo do site.
- `referencias/antes.png`: captura que mostra o excesso de branco anterior.

## Como usar

Abra o repositório na branch de trabalho e entregue `PROMPT-CLAUDE.md` e este ZIP ao Claude Code. Peça que implemente o prompt sobre `site/`. Os SVGs são vetores transparentes prontos para copiar para `site/assets/decoracao/`; não use a captura inteira como imagem do site. Revise as capturas de desktop e mobile antes de publicar.
