# Pacote Qótimo — história e unidades

Este pacote contém as referências necessárias para implementar as duas novas seções sem reconstruir fundos ou inventar fotografias.

## Pastas

- `01-mockups/`: telas completas de referência visual.
- `02-fundos/`: fundos limpos em PNG e WebP, todos com 1711 × 919 px.
- `03-referencias/`: fotografias e telas originais usadas na composição.
- `PROMPT-CLAUDE.md`: instruções completas de implementação.

## Uso recomendado

Envie o ZIP inteiro ao Claude Code, peça para ler primeiro `PROMPT-CLAUDE.md` e permita que ele examine o projeto antes de modificar arquivos.

As telas de mockup são referência de layout. Não devem ser usadas como uma imagem única dentro do site. Use os fundos da pasta `02-fundos/` como camada visual e implemente todos os textos, fotos, cards, botões e filtros em HTML/CSS.

Os endereços exibidos nos mockups são ilustrativos. O site deve utilizar exclusivamente os dados reais já existentes no projeto ou fornecidos posteriormente.
